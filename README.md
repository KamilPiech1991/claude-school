# Claude School – makieta strony

Makieta strony szkoły Claude: strona główna i strona kursu, w dwóch kierunkach wizualnych.

- `index.html` – kierunek A (ciemny)
- `kierunek-b.html` – kierunek B (jasny)
- `zrodla/` – pliki źródłowe do dalszej edycji

Pliki `index.html` i `kierunek-b.html` są samodzielne (fonty i skrypty w środku), działają bez serwera.

## Publikacja na GitHub Pages

1. Utwórz nowe repozytorium i wgraj całą zawartość tego folderu (Add file → Upload files).
2. Settings → Pages → Source: „Deploy from a branch”, Branch: `main`, folder `/ (root)` → Save.
3. Po 1–2 minutach strona będzie pod adresem `https://<login>.github.io/<repozytorium>/`.
   Kierunek B: `https://<login>.github.io/<repozytorium>/kierunek-b.html`

Treści (ceny, terminy, trenerzy, opinie) są przykładowe.
